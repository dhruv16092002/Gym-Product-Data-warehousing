# Gym Product Data Warehousing

A complete data warehousing solution designed for a gym product retail business.  
This project integrates data from various sources such as Google Sheets, SFTP files, and cloud storage using tools like **Azure Data Factory**, **Apache Airbyte**, and **Azure Blob Storage**.  
Transformed data is stored in **Azure SQL Server** and visualized through **Power BI** dashboards to enable actionable business insights and data-driven decisions.

---

## 🚀 Tech Stack & Tools Used

- **Azure Data Factory** – ETL orchestration  
- **Azure Blob Storage** – Raw data storage  
- **Apache Airbyte** – Data ingestion pipelines  
- **Azure SQL Server** – Data warehouse  
- **Power BI** – Reporting and dashboarding  
- **Google Sheets (GCP)** – Source data (Product Details & Campaign Data)
- **SFTP Files** – External data source (From CRM System)
- **SQL** – Data transformation & modeling

---

## 📊 Key Features

- Ingest data from multiple sources (SFTP, Google Sheets, APIs)
- Automate ETL workflows using Azure Data Factory
- Use Airbyte connectors for seamless extraction
- Store and organize data in Azure Blob Storage and Azure SQL
- Build interactive dashboards in Power BI for business insights
